# PATCH v6 | Reference Evidence — 电影参考的证据分层与风格迁移

Use this patch when the user gives a film name, film stills, a director, or「想要 XX 电影那种感觉」as reference. §9 的原创隔离（只抽一个主维度、禁止一眼认出原片轮廓）是底线；本 patch 补充「如何合法、诚实地从电影参考提炼并迁移视觉 DNA」，并守住不臆测、不抄片名的纪律。

适用于 Single / Triptych / Nine-Shot 三种模式。

## 1. 证据分层（先分清你知道了什么）

对每一条视觉判断，先标出它属于哪一层：

- **画面可见**：从用户给的截图 / 已看帧直接确认。
- **资料确认**：由可靠剧照、正式预告、正片片段或制作资料支持。
- **合理推断**：根据影像线索估计，必须用「可能」「接近」「推测」表述。
- **用户指定**：为新的原创提示词加入的设定，不宣称它属于原片。
- **无法判断**：当前材料不支持，不补写成事实。

只凭一张截图，不得断言真实焦段、胶片型号、摄影机型号、灯具或调色软件。需要时给「视觉等效建议」——写「接近 28–35mm 广角透视」「接近柔光硬窗光」，不写「这是 35mm 拍的」。不要把所有宽银幕都判成变形镜头：要有炫光、散景、边缘特征共同支持。

## 2. 电影参考的检索与提炼

用户只给片名时（网络可用才做）：

- 取至少 3 个互补的代表性画面 / 段落，覆盖日常、情绪转折、动作 / 高潮不同模式。
- 优先官方发行方、正式预告、制作方资料和可追溯的高质量剧照。
- 运镜 / 剪辑只能从连续影像或可靠描述提炼，不能从单帧臆测。
- 结论附来源链接，把「资料事实」和「我的视觉判断」分开写。

用户给截图时，先逐张分析，再提炼重复规律、可变模式和异常项。

## 3. 视觉 DNA 收束形式

多张参考分析完，用一句固定结构收束，再进入迁移：

> 视觉 DNA = 稳定规律（3–5 条跨画面反复出现）+ 场景变体（日常 / 动作 / 夜景等如何变化）+ 禁止偏差（最容易误生成的相反风格）。

## 4. 风格迁移规则（把片名翻译成可执行参数）

- 先提炼稳定规律，再选择与新场景相关的部分，不整段照搬。
- 保留「结构关系」，而不是复制画面：例如「暖灰日常空间 + 深焦群体调度 + 突然进入冷色低调奇观」。
- 片名 / 导演名只作参考索引，最终必须转译成布景、服装、光源、构图、材质、曝光事实——即使模型不认识片名，提示词也成立。
- 不复制原片角色肖像、标志性场面或逐帧构图（承接 §9 底线）。
- 新场景与参考风格冲突时，优先满足用户叙事目标，并说明取舍。

## 5. 静帧诚实边界（本 skill 只出静帧）

cinema-dna 交付的是静态电影静帧，不是视频：

- 单帧提示词不写时间过程（「先推进再拉远」），改用静态视觉结果——「带有逼近感的广角透视」「主体处于动作中途、前后景有视差拖影」。
- 静帧只能描述可见状态，不断言实际运动速度或真实运镜路径。
- 用户给「运镜参考」要求复刻时，把运镜语言转译成静帧里的运动痕迹：motion blur、主体在画面中的位置、前景 / 背景相对清晰度、焦点转移的痕迹、稳定方式对应的成像性格（手持微晃→轻微 blur；锁定三脚架→静态构图）。

## 6. V6 自检

- 每条结论是否标了证据层级（可见 / 资料 / 推断 / 用户指定 / 无法判断）？
- 是否误从静帧臆测了焦段、胶片、摄影机、灯具或调色软件？
- 是否只写了「某电影同款 / 某导演风格」，没转译成可执行参数？
- 是否保留了结构关系而非复制肖像、标志场面或逐帧构图？
- 单帧提示词是否误写了时间过程（推进 / 拉远）而没有落到静态瞬间？
- 是否把运镜语言正确转译成了静帧的运动痕迹？
